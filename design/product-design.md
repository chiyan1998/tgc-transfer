## 1. 功能范围

### MVP（必须有）

| 功能 | 说明 |
| --- | --- |
| 账户登录/注册 | email + 密码；注册开关由环境变量控制 |
| 多源订阅管理 | 期刊（Crossref 检索）+ arXiv 学科分类 + NBER；用户各自维护订阅列表 |
| 信息流 | 按订阅源聚合的文章/工作论文流，时间倒序，无限滚动 |
| 筛选 | 按源/平台、时间范围（今日/本周/全部）、已读/未读、是否有 OA PDF |
| 快速概要（默认展示） | 每张卡片自动展示：中文标题/摘要 + 研究领域、论文类型标签（五分类多标签）、研究问题、研究结论 |
| 深度阅读（占位） | 卡片预留入口；接入用户上传的阅读技能后按论文类型生成深度笔记（需 PDF）；当前置灰提示"技能开发中" |
| 附录与数据集 | 卡片可触发"查找附录/数据"，展示下载链接或跳转（含 Dataverse） |
| 刷新控制 | 登录自动增量刷新（可关闭）+ 用户自定义刷新频率 + 顶栏/源中心手动刷新 |
| 文章详情 | 侧滑抽屉：完整摘要、作者、卷期页码、DOI 链接、PDF 链接、资源列表 |
| 已读/收藏 | 卡片自动标记已读、收藏列表 |
| 密钥安全 | Key 仅服务端可见，启动自检，admin 面板脱敏展示（见 architecture §7） |
| 书籍资讯 | Crossref 图书订阅（按出版社），新书发布资讯；卡片仅翻译+基本信息（书名/作者/出版社/ISBN/封面），无深度阅读与资源发现 |
| 预留模块入口 | 顶导航含学术会议 / 基金资助 / 项目管理三个预留入口，渲染"规划中"占位页；阅读笔记已启用材料上传（见 §3.4） |

- SSRN 工作论文接入（无官方 API，待单独评估）
- 关键词订阅（不限定源，按主题词聚合）
- 邮件/桌面推送日报、全文检索与标签、团队共享书单

## 2. 页面结构

```
/                  → 重定向到 /feed
/login, /register  → 认证（共享品牌布局：左侧吉祥物+平台名，右侧表单卡片；登录含未验证/锁定错误态与重发验证入口）
/verify-email      → 邮箱验证引导（注册后跳转；重发 60s 冷却，另去登录入口）
/feed              → 信息流（主页，含顶栏批量生成摘要 + 手动刷新）
/sources           → 订阅中心：期刊搜索 + arXiv 分类 + NBER + 单源刷新/退订
/saved             → 收藏列表
/settings          → 个人设置：账号区（昵称、邮箱+验证状态徽标、修改密码、退出登录）、刷新策略（登录自动刷新开关、频率）、模型配置、阅读笔记 Obsidian 目录（保存/检查）、数据导出（admin：数据库备份 + 用户管理）
/about             → 关于：项目全称/版本号/更新时间、作者信息、打赏码占位、「我要反馈」弹窗（概述+详情+图片/PDF 附件）
/conferences       → 预留：学术会议信息收集平台（占位页）
/funding           → 预留：基金/助学金/奖学金信息平台（占位页）
/projects          → 预留：工作与研究项目管理系统（占位页，仅入口）
/notes             → 阅读笔记（材料上传）：论文正文（PDF/EPUB）与附加材料（PDF/ZIP）拖拽/点选上传 + 已上传列表（文件名/大小/时间/删除）；笔记自动生成功能开发中
```

## 3. 关键页面设计

### 3.1 信息流 `/feed`

```
┌──────────────────────────────────────────────────────────┐
│ 文献集市  [筛选: 全部源 ▾][本周 ▾][☑仅OA]  [⟳ 刷新]  👤   │
├──────────────────────────────────────────────────────────┤
│ ⓘ 有 12 篇新文章（点击刷新）                              │
├──────────────────────────────────────────────────────────┤
│ Nature · 2小时前                        [★] [✓已读] [中/EN]│
│ 基于xxx的yyy方法研究（中文标题）                          │
│ [量化实证] [方法论]   领域：计量经济学                    │
│ 研究问题：中文一句话…                                     │
│ 结论：中文一两句话…                                       │
│ [PDF ⭳] [深度阅读(占位)] [查找附录/数据] [详情]           │
├──────────────────────────────────────────────────────────┤
│ arXiv econ.EM · 5小时前                                   │
│ …（无限滚动）                                            │
└──────────────────────────────────────────────────────────┘
```

交互规则：
- 顶部统计行：「当前共有论文 x 篇，已自动摘要 x 篇 · 上次自动更新 YYYY-MM-DD HH:mm」（北京时间，来自 `/api/stats/feed`）；挂载后每 30 秒静默轮询，批量/回填进行中数字自然增长。
- 搜索：范围下拉旁输入框（防抖 500ms），按英文/中文标题、来源/期刊名检索（`q` 参数）。
- 筛选面板（可折叠多选）：论文类别（期刊论文/工作论文）、来源类型（期刊/arXiv/NBER）、论文类型（五分类多选）、具体来源（动态读已订阅源列表多选，限高滚动，与其余筛选 AND 叠加）；日期沿用 6 档范围下拉；筛选激活时显示「清除筛选」；任一变更重置游标重新加载。
- 排序：筛选栏排序下拉（入库时间/发表日期/来源名/摘要状态）+ 方向切换按钮（↑↓），变更即重置加载；后端键集游标翻页（游标以 a.id 定位，来源名排序极端跨界允许轻微误差）。
- 全站时间展示统一为北京时间（Asia/Shanghai）；数据库仍以 UTC 存储，显示端经 `src/lib/time.ts` 转换。
- 卡片进入视口 2s 自动标记已读；概要生成中显示骨架屏占位。
- 待摘要卡片（基线分层）：非基线源且无人配置个人模型的文章显示「待摘要」徽标 + 「生成摘要」按钮；点击后已配置个人概要模型则入队（手动优先级，豁免每日额度），未配置则提示去设置页；生成后卡片轮询自动切换为四要素概要。
- 来源行两级区分：前缀徽标「期刊论文」/「工作论文」 + 仓库各自配色（期刊=玫红系、arXiv=蓝色系、NBER=绿色系）；期刊旁显示发表日期（优先 Online 日期标「Online」，否则标「发表」）与卷期（Vol.x(y)），工作论文显示发布/提交日期。
- 四要素区每行一条：左侧固定宽度标签徽标（研究领域/论文类型/研究问题/研究结论）+ 右侧正文，与卡片标题区拉开层次；论文类型为彩色小标签（五分类各一色，仅中文）。
- 「生成引用」弹窗：APA 7th / Chicago / IEEE / Nature / APSA / BibTeX / BibLaTeX 七格式 Tab 切换 + 一键复制（引文用英文原题信息）。
- 范围筛选：今天/最近一周/最近一月（默认）/最近三个月/最近半年/全部时间；选「全部时间」时顶部黄色提示：回翻耗时较长且概要生成消耗较多 Token。
- 「深度阅读」技能未接入前置灰，悬浮提示"技能开发中"。
- 「查找附录/数据」触发后按钮变进度态；完成后在详情抽屉展示资源列表（下载或新标签页跳转）；无结果明示。
- 顶栏「⟳ 刷新」立即刷新全部订阅源（防抖 60s）；旁侧「批量生成摘要」按钮（所有登录用户可见）→ 弹窗：具体来源多选（已订阅列表，标注基线/个人模型）+ 日期 6 档下拉 → 「预览篇数」显示将摘要 N 篇（另 M 篇受额度跳过 / K 篇需先配个人模型）→ 「确定生成」入队（0 篇禁用）；基线源走全局模型，非基线源计入触发者每日额度。

### 3.2 订阅中心 `/sources`

- 顶部「仪表盘 · Token 消耗」区块：今日/近 7 日/累计三个大数字 + 热力图（横轴近 90 天、纵轴 4 时段：深夜 0-6 / 上午 6-12 / 下午 12-18 / 晚间 18-24），格子深浅代表消耗量，悬停显示具体日期时段与 Token 数。
- 五个分区：**期刊**（Crossref 检索：刊名/ISSN → 订阅）、**arXiv**（预置学科分类列表勾选，如 econ.EM、cs.LG）、**NBER**（一键订阅）、**书籍**（按出版社订阅，Crossref 出版社检索，定位新书资讯）、预留 **SSRN** 分区（灰置）。
- 已订阅列表：源名/平台、最近抓取时间、上次新增数、「立即更新」「退订」；期刊可补充 RSS 地址。
- 基线分层：基线源（开发者标记，仅 admin 可切换「设为基线」开关，普通用户只显「基线」徽标）的抓取+摘要全部由开发者全局模型承担；设为基线时存量无概要文章全部回填队（提示「已加入 N 篇待摘要」），取消基线删除未开始的基线任务（已完成概要保留）；非基线源仅抓取入库，摘要按订阅者个人概要模型生成（见 §3.3）。
- 书籍卡片样式简化：中文书名 + 作者/出版社/ISBN/出版日期/封面，无 PDF、深度阅读、资源查找入口。

### 3.3 设置 `/settings`

- 刷新策略：登录时自动刷新（开关）+ 期望刷新频率（下拉：15/30/60/120 分钟）。
- 模型配置（三个区块）：「快速概要模型」全局共享、由开发者统一配置并承担费用，界面对所有用户只读（有框不可填），灰置框下方展示当前生效的模型与提供商（不展示 API Key）；上线后配置写在云服务器（环境变量或数据库），启动时自动读取。「个人概要模型（范围外摘要）」每用户可写（`brief_personal` 槽），用于非基线订阅源的自动摘要，同区含每日自动摘要上限（篇数，0=仅手动触发，超限任务排队至次日）与优先摘要订阅源多选（仅影响调度顺序）。「阅读笔记模型」每用户独立可写，含提供商 URL、模型名称、API Key（AES-256-GCM 加密入库，界面仅回显掩码）与「测试连接」；概要配置优先级：DB 配置 > `.env.local`。
- 账号（账号体系升级）：昵称修改；邮箱只读 + 已验证/未验证徽标；修改密码（校验旧密码，新密码 ≥8 位且含字母与数字）；退出登录。注册需邮箱验证（验证邮件链接 24h 有效、一次性）；登录门禁：未验证拦截可重发邮件，连续 5 次失败锁定 15 分钟；找回密码暂不做，文案指引联系管理员重置。
- 用户管理（仅 admin）：用户表格（角色切换不可降级自己、验证状态徽标与手动标记已验证）+ 创建账号（直接已验证，随机初始密码一次性回显）；数据导出（收藏/订阅列表）。
- 阅读笔记 · Obsidian 目录：目录路径输入 + 「保存」「检查」按钮；检查调 `/api/settings/vault-check` 服务端真实校验（存在 + 是目录 + 含 `.obsidian`），展示三类失败提示；文案注明校验仅在应用运行于本机时有效。
- Admin：LLM Key 连通性与脱敏展示、队列积压、数据库备份按钮。

### 3.4 预留模块占位页规范（`/conferences` `/funding` `/projects`）

- 统一占位组件：吉祥物图标 + 模块名 + 一句话定位 + 「规划中」状态徽章 + 返回信息流按钮。
- 定位文案：会议="截稿日期与征稿信息聚合"；基金="基金/助学金/奖学金机会聚合"；项目="工作与研究项目管理（复杂系统，待启动）"。
- `/notes` 已启用（见 §2）：两块上传卡——论文正文（PDF/EPUB）、附加材料（PDF/ZIP），拖拽或点选，单文件 ≤50MB；下方已上传列表（文件名/大小/时间/删除）；底部提示笔记自动生成功能开发中。
- 导航状态由 `GET /api/modules` 驱动，模块启用后只改注册表即切换为可用。

### 3.5 关于 `/about`

- 居中吉祥物大图 + 项目全称「虎妞小猫学术信息中转站（TGC Transfer）」+ 版本号与上次版本更新时间（`src/lib/version.ts` 手工维护，随发版更新）。
- 作者信息：姓名 / 邮箱（mailto）/ GitHub 主页；打赏区并排展示微信、支付宝两张收款码（裁剪自原始截图的核心二维码，`public/donate-weixin.png` / `donate-alipay.png`，分别标注微信/支付宝），下方附 Buy me a coffee 文案。
- 「我要反馈」→ 页内弹窗：问题概述（单行必填）+ 详情描述（多行）+ 附件上传（图片与 PDF，单文件 ≤10MB，最多 3 个，前端与后端双重校验）；提交后存 `feedbacks` 表，附件落盘 `data/uploads/YYYYMM/`。

## 4. 关键用户流程

### 首次使用

```
注册/登录 → 订阅中心添加期刊 + arXiv 分类 + NBER（或跳过）
→ 立即触发首次抓取（回填 30 天）+ 自动生成快速概要 → 信息流浏览 → 在设置里调整刷新偏好
```

### 日常浏览（每次登录）

```
登录 → 自动增量刷新订阅源（后台，不阻塞）
→ 信息流扫视快速概要（领域/类型/问题/结论）判断相关性
→ 值得精读 → 深度阅读（技能接入后）/ 查找附录与数据集 / 点 DOI·PDF 外链
→ 收藏备查；需要最新时手动点顶栏「⟳ 刷新」
```

## 5. 非功能性要求

| 项 | 目标 |
| --- | --- |
| 快速概要时效 | 新文章入库后 ≤ 5 分钟出现概要 |
| 登录刷新 | 增量刷新不阻塞首屏，完成后信息流顶部提示新增数量 |
| 更新时效 | 源发布后 ≤ 1 小时进入信息流（受上游收录时延影响） |
| 性能 | 信息流首屏 < 1s（本地部署），单页 20 条 |
| 容量假设 | ≤ 10 用户、≤ 50 订阅源/人、百万级文章记录（SQLite 可支撑） |
| 安全 | 见 architecture §7：密钥五层防护 + SSRF 防护 + 限流 |
